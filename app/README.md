# 🎙️ AI 同声传译助手

AI Simultaneous Interpretation Assistant — 将单向音频流实时、流畅地翻译成目标语言，以字幕或语音形式呈现，帮助用户降低语言门槛，提升信息获取效率。

## 功能特性

### 核心能力
- **🎧 实时语音识别 (ASR)** — 通过 WebSocket 连接讯飞云端语音识别引擎，实时将语音转为文字
- **🈶 多语言互译** — 支持中↔英↔日↔韩等多种语言自由互译，目标语言可配置
- **📝 双语字幕** — 原文 + 译文双行字幕展示，适合观看演讲、会议、网课
- **🔊 语音播报** — 集成 Web Speech API，将翻译结果以语音合成播报
- **✏️ 自动纠错** — API 级纠错机制：中间结果变化时自动修正，以删除线 + 箭头动画展示

### 交互体验
- **🎤 麦克风实时采集** — 一键开始/停止录音，支持空格键快捷操作
- **📁 音频文件上传** — 支持上传 WAV 等音频文件，模拟实时流式播放
- **🌙 明暗主题切换** — 暗色/亮色主题一键切换，`localStorage` 持久化
- **🔠 字体大小调节** — 10px~28px 滑块实时调节字幕和列表字号
- **⛶ 全屏字幕模式** — 隐藏所有面板，仅保留超大双语字幕，按 ESC 退出
- **🔍 历史搜索** — 实时搜索过滤转录记录中的原文或译文
- **📊 实时统计** — 显示已识别语句数、自动纠正次数、录制时长
- **📄 记录导出** — 支持 SRT 字幕、TXT 纯文本、HTML 网页三种格式导出

## 快速开始

### 1. 配置环境变量

编辑 `.env` 文件，填入你的 API 凭证：

```bash
# 服务端口
PORT=3000

# ASR API 地址 (讯飞实时语音识别)
ASR_BASE_URL=wss://rtasr.xfyun.cn/v1/ws

# API 凭证 (讯飞)
TRANSLATE_APP_ID=your_app_id
TRANSLATE_APP_SECRET=your_app_secret

# (可选) 留空则不使用
ANTHROPIC_API_KEY=
```

### 2. 安装依赖并启动

```bash
cd app
npm install
npm start
```

### 3. 打开浏览器

访问 `http://localhost:3000`，点击麦克风按钮或按空格键开始使用。

## 使用说明

| 操作 | 说明 |

| 🎤 点击麦克风 | 开始/停止实时录音 |

| 源语言/目标语言 | 实时切换翻译语言对，修改后自动重连 ASR |
| 场景选择 | 切换识别场景（教育/科技/金融等）|
| TTS 开关 | 开启后自动播报翻译结果 |
| 🌙 主题切换 | 切换暗色/亮色主题 |
| 🔠 字体大小 | 滑块调节 10px~28px |
| ⛶ 全屏字幕 | 进入全屏字幕模式 |
| 🔍 搜索 | 在历史记录中搜索原文或译文 |
| 📄 导出 | 选择格式导出完整转录记录 |

## 支持的语言

**源语言**：中文、英语、日语、韩语、法语、德语、西班牙语、俄语、自动检测。

**目标语言**：中文、英语、日语、韩语。前端语言选择自动映射为 Google Translate API 格式（如 `zh` → `zh-CN`）。

## 导出格式

| 格式 | 文件扩展名 | 说明 |
|------|-----------|------|
| SRT | `.srt` | 标准字幕格式，可直接用于视频播放器 |
| TXT | `.txt` | 纯文本，带时间戳的双语对照 |
| HTML | `.html` | 可打印的表格页面，支持浏览器打印为 PDF |

## 技术栈

- **后端**: Node.js + Express + ws
- **前端**: 原生 HTML/CSS/JS (Web Audio API + Web Speech API + WebSocket)
- **音频格式**: PCM 16kHz 16bit 单声道
- **传输协议**: WebSocket (ws)
- **ASR**: 讯飞 rtasr (`wss://rtasr.xfyun.cn/v1/ws`)
- **翻译**: Google Translate 免费 API（无需 API Key）

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/history/:sessionId` | 获取当前会话历史记录 |
| GET | `/api/export/:sessionId?format=srt\|txt\|html` | 导出转录记录 |
| POST | `/api/refine` | 重新翻译 (保留接口，当前由 Google Translate 驱动) |
| WS | `/ws` | 实时 WebSocket 通信 |
