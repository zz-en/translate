# AI 同声传译助手 — 功能介绍 Demo 稿

## 录制准备

- [ ] 打开 Chrome/Edge 浏览器，进入 `http://localhost:3000`
- [ ] 确保麦克风可用（右下角不显示静音图标）
- [ ] 准备一段英文视频/音频用于测试上传（或准备说几句英文）
- [ ] 屏幕录制工具就绪（OBS / Windows自带录屏 Win+G / 其他）

---

## Demo 步骤 & 稿子

### 场景 0：开场（30秒）

**操作**：打开浏览器，展示首页

**稿子**：
> "大家好，今天给大家介绍一个我开发的工具——**AI 同声传译助手**。它可以实时识别语音、自动翻译成多国语言，而且完全免费，不需要任何付费 API。
>
> 首页这里能看到六个功能模块：同声传译、对话模式、音频上传、全屏字幕、桌面字幕和历史导出。我们一个一个来看。"

---

### 场景 1：同声传译 — 核心功能（1 分钟）

**操作**：
1. 点击首页「**同声传译**」卡片或左侧「🎙 同声传译」
2. 确认右上角连接状态显示「● 已连接」
3. 右侧设置面板选择源语言：**英语** → 目标语言：**中文**
4. 点击底部蓝色「**🎤 开始录音**」按钮
5. 对着麦克风说一段英文（例如：*"Hello everyone, today I'm going to demonstrate a real-time translation tool that I built. It can recognize speech and translate it instantly."*）
6. 观察：
   - 底部字幕区实时显示原文和译文
   - 上方历史记录区逐句积累
   - 右侧统计数字变化（已识别语句、录制时长）
7. 点击「⏹ 停止录音」

**稿子**：
> "先看最核心的同声传译功能。我选择英语→中文，点开始录音。
>
> *（开始说话）*
>
> 大家看，我说英文的同时，底部这里**实时**出现了原文和中文翻译。上面的历史记录也在滚动积累。整个过程延迟不到一秒，基本是边说边翻。
>
> 右侧可以看到统计信息：识别了多少句、录制了多久。右边设置面板还能切换其他语言——日语、韩语、法语都支持。
>
> 每个翻译结果旁边有个 ✨ 按钮，这是 AI 润色功能。如果配置了 DeepSeek API Key，点一下就能让 AI 把机翻结果润色得更自然。"

---

### 场景 2：对话模式 — 双向互译（1 分钟）

**操作**：
1. 点击左侧「💬 **对话模式**」
2. 点击快捷预设「**中 ↔ 英**」
3. 点击「🎤 开始对话」
4. 先说中文（如 "你好，请问这个怎么用？"），再说英文（如 *"It's very simple, just press the button and speak."*）
5. 观察左右气泡：中文显示在左侧蓝色气泡（你），英文显示在右侧紫色气泡（对方），每条下面自动带翻译
6. 点击「⏹ 停止对话」
7. （可选）如果配了 DeepSeek，点击「📋 生成会议纪要」→ 弹窗展示 AI 生成的对话总结

**稿子**：
> "接下来是**对话模式**，这个特别适合两个人说不同语言的时候用。
>
> 我设置我是中文，对方是英语。上面有快捷预设，一键切换中英、中日、中韩。
>
> 开始对话后，我说中文，它自动识别、翻译成英文给对方看。对方说英文，自动翻译成中文给我看。左右分开显示，非常直观。
>
> 对话结束后，点「生成会议纪要」，AI 会把整个对话整理成结构化的纪要——包括讨论要点、结论和待办事项。这对开会特别有用。"

---

### 场景 3：音频上传 — 视频/音频文件识别（1 分钟）

**操作**：
1. 点击左侧「📁 **音频上传**」
2. 点击上传区域，选择一个 MP4 视频文件（或 MP3/WAV 音频文件）
3. 观察进度条：显示「识别中 X% (Xs/总时长s)」
4. 等待完成后自动跳转到同声传译模块
5. 查看识别结果：原文 + 译文逐条显示在历史记录中

**稿子**：
> "有时候我们不是实时说话，而是有一个现成的音频或者视频需要翻译。这时候用**音频上传**功能。
>
> 支持 MP3、WAV 格式的音频，也支持 **MP4 视频**——它会自动提取视频里的音频轨道。
>
> 我上传一个英文视频，可以看到进度条在走，实时显示识别进度。处理完成后自动跳到同声传译界面，所有的识别结果和翻译都在这里。
>
> 这个功能特别适合：会议录音翻译、英文课程翻译、YouTube 视频字幕生成。"

---

### 场景 4：全屏字幕 — 投屏/演示（30 秒）

**操作**：
1. 先回到「同声传译」模块开始录音
2. 点击左侧「🔤 **全屏字幕**」
3. 展示大字双语字幕（原文 28px / 译文 42px，居中显示）
4. 按 ESC 或点返回

**稿子**：
> "如果在会议、演讲、或者上课的场景，可以让观众看**全屏字幕**。它跟同声传译模块是实时联动的。
>
> 你看这个字号非常大，原文 28 像素，译文 42 像素。投屏到大屏幕上，坐在后排也看得清清楚楚。"

---

### 场景 5：桌面字幕 — 悬浮窗（30 秒）

**操作**（仅 Chrome 116+ 支持 Document PiP）：
1. 点击「🖥️ **桌面字幕**」
2. 点击「🎤 麦克风识别」或「🔊 系统音频」
3. 展示悬浮窗浮在所有窗口上方
4. 拖动透明度滑块演示纯字幕模式
5. 点「⏹ 停止字幕」

**稿子**：
> "桌面字幕是一个**悬浮窗**，始终置顶在所有窗口上面。适合你看视频、开在线会议的时候，字幕浮在画面下方。
>
> 支持麦克风模式和系统音频模式。还能调透明度——拉到 0% 就是纯字幕，像网易云桌面歌词一样，只显示文字没有背景。"

---

### 场景 6：历史导出 + AI 配置（30 秒）

**操作**：
1. 点击「📜 **历史导出**」
2. 展示转录记录列表
3. 搜索框输入关键词搜索
4. 选择导出格式（SRT / TXT / HTML），点击导出
5. 点击右侧 AI 状态指示器 → 弹出 API Key 配置窗口
6. 展示输入框和保存流程

**稿子**：
> "所有识别记录都可以在历史导出模块查看。支持搜索，还能导出成 **SRT 字幕、TXT 文本或 HTML 网页**格式。
>
> 如果想用 AI 润色功能，点右侧这个 AI 状态指示器，输入 DeepSeek 的 API Key 就能启用。DeepSeek 国内直接访问，价格非常便宜，100 万 token 才一块钱。"

---

**操作**：

2. 拖动字体大小滑块
3. 展示调整后的效果

**稿子**：
> "还有一些贴心的功能：明暗主题切换，字体大小可以调，所有的列表和面板都支持鼠标滚轮上下滚动。整个界面是深蓝紫色科技风，晚上用也不刺眼。"

## 注意事项

1. **录音前确认**麦克风权限已授权（Chrome 地址栏左侧锁图标）
2. **视频上传**建议用 1 分钟以内的短视频，识别更快
3. **桌面字幕**需要 Chrome 116+，不支持的话会自动切换到全屏字幕模式
4. **AI 功能**需要提前在 [platform.deepseek.com](https://platform.deepseek.com) 注册获取 Key
5. 录制时建议开**隐身模式**以避免浏览器插件干扰
